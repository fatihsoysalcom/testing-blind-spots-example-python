# Testing Blind Spots Example Python

This example demonstrates how a developer's initial assumptions can create 'blind spots' in their test suites. It features a simple function `calculate_average` with a hidden flaw for an edge case (an empty list). The example shows a set of tests that pass based on expected inputs, followed by a 'blind spot' test specifically designed to reveal the flaw, highlighting the importance of considering unexpected scenarios.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
